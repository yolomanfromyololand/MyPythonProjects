## Запуск

Нужен Python 3. Для лабораторных 06 и 07 установите зависимости из корня репозитория:

```powershell
python -m pip install -r requirements.txt
```

Запускайте программу из папки её лабораторной: исходные решения открывают файлы данных по относительным путям. Например:

```powershell
cd Lab05_File_IO
python task01_read_text_files.py
```

Для некоторых заданий требуется ввод с клавиатуры. Программы записи файлов и построения графиков могут перезаписывать результаты в своей папке.
