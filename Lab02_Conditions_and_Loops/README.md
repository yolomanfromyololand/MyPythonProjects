# Lab02_Conditions_and_Loops

Условия и циклы.

**Цель:** Ветвления if/elif/else, логические условия, циклы while/for, break и continue.

## Задания

| Исходный файл | Новый файл | Что делаю |
| --- | --- | --- |
| `task1.py` | [task01_check_number_ranges.py](task01_check_number_ranges.py) | Преобразовать ввод в целое число и проверить границы диапазона. |
| `task2.py` | [task02_if_else_number_check.py](task02_if_else_number_check.py) | Проверить введённое число с помощью if/else. |
| `task3.py` | [task03_compare_string_lengths.py](task03_compare_string_lengths.py) | Сравнить длины двух строк через if/elif/else. |
| `task4.py` | [task04_calculate_income_tax.py](task04_calculate_income_tax.py) | Рассчитать налог с учётом дохода и семейного положения с помощью вложенных условий. |
| `task5` | [task05_while_loop_counter.py](task05_while_loop_counter.py) | Вывести последовательность чисел и проследить условие завершения while. |
| `task6` | [task06_repeat_until_valid_pin.py](task06_repeat_until_valid_pin.py) | Запрашивать PIN в цикле до правильного ввода и проверять его формат. |
| `task7` | [task07_square_roots_break_and_continue.py](task07_square_roots_break_and_continue.py) | Вычислять квадратные корни; пропускать отрицательные числа через continue и завершать цикл при нуле через break. |
| `task8.py` | [task08_sum_even_numbers.py](task08_sum_even_numbers.py) | Найти сумму чётных чисел от 1 до 100 с помощью for и условия. |

## Запуск

Из корня репозитория:

```powershell
cd Lab02_Conditions_and_Loops
python task01_check_number_ranges.py
```

Для другого задания замените имя скрипта на нужное из таблицы. Запускайте скрипты из этой папки, чтобы относительные пути к данным работали.
