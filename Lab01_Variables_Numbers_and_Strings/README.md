# Lab01_Variables_Numbers_and_Strings

Переменные, числа и строки.

**Цель:** Типы данных, ввод, арифметика, строковые операции и форматирование.

## Задания

| Исходный файл | Новый файл | Что делаю |
| --- | --- | --- |
| `task1.py` | [task01_variables_and_types.py](task01_variables_and_types.py) | Изменить значение и тип переменной; вывести значение и его тип. |
| `task2.py` | [task02_concatenate_strings.py](task02_concatenate_strings.py) | Объединить две строки и вывести сообщение. |
| `task3.py` | [task03_arithmetic_operations.py](task03_arithmetic_operations.py) | Ввести два числа и выполнить основные арифметические операции. |
| `task4.py` | [task04_calculate_circle_area.py](task04_calculate_circle_area.py) | Рассчитать площадь круга по введённому радиусу с помощью math.pi. |
| `task5.py` | [task05_string_methods_and_formatting.py](task05_string_methods_and_formatting.py) | Перевести имя в верхний регистр и составить поздравление с помощью format(). |
| `task6.py` | [task06_string_indexing_and_slicing.py](task06_string_indexing_and_slicing.py) | Извлечь отдельные символы и фрагменты строки по индексам и срезам. |
| `task7.py` | [task07_format_decimal_output.py](task07_format_decimal_output.py) | Умножить числа и вывести результат с двумя знаками после запятой. |
| `task8.py` | [task08_compare_number_and_string_operations.py](task08_compare_number_and_string_operations.py) | Сравнить операции с числами и строками; проверить индексы и срезы. |

## Запуск

Из корня репозитория:

```powershell
cd Lab01_Variables_Numbers_and_Strings
python task01_variables_and_types.py
```

Для другого задания замените имя скрипта на нужное из таблицы. Запускайте скрипты из этой папки, чтобы относительные пути к данным работали.
