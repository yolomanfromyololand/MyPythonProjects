# Lab00_Python_and_GitHub_Setup

Настройка Python и GitHub.

**Цель:** Запуск первого Python-скрипта и проверка настройки рабочего окружения.

## Задания

| Исходный файл | Новый файл | Что делаю |
| --- | --- | --- |
| `hello.py` | [hello_python_and_github.py](hello_python_and_github.py) | Вывести приветствие и сообщение о настройке GitHub. |

## Запуск

Из корня репозитория:

```powershell
cd Lab00_Python_and_GitHub_Setup
python hello_python_and_github.py
```

Для другого задания замените имя скрипта на нужное из таблицы. Запускайте скрипты из этой папки, чтобы относительные пути к данным работали.
