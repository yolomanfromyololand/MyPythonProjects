# Lab03_Functions

Функции и аргументы.

**Цель:** Определение функций, параметры, возвращаемые значения, аргументы по умолчанию, именованные аргументы и *args.

## Задания

| Исходный файл | Новый файл | Что делаю |
| --- | --- | --- |
| `task1.py` | [task01_check_for_even_number.py](task01_check_for_even_number.py) | Написать функцию, которая проверяет наличие чётного числа в списке. |
| `task2.py` | [task02_filter_even_numbers.py](task02_filter_even_numbers.py) | Вернуть из функции список всех чётных чисел. |
| `task3.py` | [task03_add_numbers_with_function.py](task03_add_numbers_with_function.py) | Передать два введённых числа в функцию и вернуть их сумму. |
| `task4.py` | [task04_calculator_with_default_arguments.py](task04_calculator_with_default_arguments.py) | Создать калькулятор с параметром операции по умолчанию и позиционными аргументами. |
| `task5.py` | [task05_calculator_with_keyword_arguments.py](task05_calculator_with_keyword_arguments.py) | Вызвать калькулятор с именованными аргументами в разном порядке. |
| `task6.py` | [task06_get_initials_with_args.py](task06_get_initials_with_args.py) | Принять произвольное число имён через *args и вернуть инициалы. |

## Запуск

Из корня репозитория:

```powershell
cd Lab03_Functions
python task01_check_for_even_number.py
```

Для другого задания замените имя скрипта на нужное из таблицы. Запускайте скрипты из этой папки, чтобы относительные пути к данным работали.
