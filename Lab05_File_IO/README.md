# Lab05_File_IO

Чтение и запись файлов.

**Цель:** Текстовые файлы, read/readline/readlines, запись, добавление, обработка строк и отчёты.

## Задания

| Исходный файл | Новый файл | Что делаю |
| --- | --- | --- |
| `task1.py` | [task01_read_text_files.py](task01_read_text_files.py) | Прочитать текст целиком, построчно и в список с помощью read(), readline() и readlines(). |
| `task2.py` | [task02_write_and_append_text.py](task02_write_and_append_text.py) | Записать строки о фруктах в файл, добавить строку и вывести содержимое. |
| `task3.py` | [task03_count_words_per_line.py](task03_count_words_per_line.py) | Записать стихотворение и подсчитать слова в каждой строке. |
| `task4.py` | [task04_merge_python_and_machine_code.py](task04_merge_python_and_machine_code.py) | Объединить строки Python и соответствующий машинный код в один выходной файл. |
| `task5.py` | [task05_analyse_student_grades.py](task05_analyse_student_grades.py) | Загрузить имена и оценки в словарь, найти лучшего студента и среднюю оценку. |
| `task6.py` | [task06_write_student_grade_report.py](task06_write_student_grade_report.py) | Создать отчёт с буквенными оценками и дописать итоговую статистику. |

## Запуск

Из корня репозитория:

```powershell
cd Lab05_File_IO
python task01_read_text_files.py
```

Для другого задания замените имя скрипта на нужное из таблицы. Запускайте скрипты из этой папки, чтобы относительные пути к данным работали.
